# 🤖 ربات ویدیوی آموزشی تلگرام

ربات تلگرام برای توزیع ویدیوهای آموزشی با سیستم عضویت اجباری در کانال‌های اسپانسر.

## ✨ امکانات

- 🎬 ارسال ویدیو با Deep Link اختصاصی
- 📢 بررسی عضویت در کانال‌های اسپانسر
- 🗑️ حذف خودکار ویدیو بعد از 30 ثانیه
- 📊 پنل آمار کامل
- 📣 برودکست به همه کاربران
- ⚙️ مدیریت اسپانسرها از داخل ربات
- 📈 شمارنده بازدید هر ویدیو
- 🔒 محدودیت دانلود روزانه

## 🚀 راه‌اندازی

### 1. کلون و نصب

```bash
git clone <your-repo>
cd telegram-video-bot
npm install
```

### 2. تنظیم Environment

```bash
cp .env.example .env
```

فایل `.env` رو باز کن و مقادیر رو پر کن:

| متغیر | توضیح |
|--------|--------|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | آیدی عددی تلگرامت (از [@userinfobot](https://t.me/userinfobot)) |
| `MAIN_CHANNEL_ID` | آیدی عددی کانال اصلی |
| `VIDEO_DELETE_DELAY` | مدت زمان نمایش ویدیو (ثانیه) |
| `DAILY_LIMIT` | محدودیت دانلود روزانه (0 = بدون محدودیت) |

### 3. اجرا

```bash
# حالت توسعه (با auto-restart)
npm run dev

# حالت اجرا
npm start
```

## 📖 نحوه استفاده

### دستورات ادمین

| دستور | عملکرد |
|--------|--------|
| `/panel` | باز کردن پنل مدیریت |
| `/add` | اضافه کردن ویدیو جدید |

### فرآیند اضافه کردن ویدیو

1. دستور `/add` رو بزن
2. ویدیو رو با کپشن دلخواه بفرست
3. ربات لینک و دکمه آماده رو بهت میده
4. پست رو در کانال فوروارد یا کپی کن

### اضافه کردن اسپانسر

از پنل → مدیریت اسپانسرها → افزودن اسپانسر جدید:

```
-1001234567890 | نام کانال | https://t.me/channel_username
```

> ⚠️ **مهم:** ربات باید ادمین کانال‌های اسپانسر باشد!
