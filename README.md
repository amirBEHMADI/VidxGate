# ربات ویدیویی تلگرام

ربات تلگرام برای اشتراک‌گذاری ویدیو از طریق دیپ‌لینک به همراه سیستم عضویت اجباری در کانال‌های اسپانسر.

## امکانات

- ارسال ویدیو با Deep Link اختصاصی
- بررسی خودکار عضویت کاربر در کانال‌های اسپانسر
- حذف خودکار ویدیو پس از زمان تعیین‌شده
- پنل مدیریت و آمار (تعداد کاربران، ویدیوها و بازدیدها)
- ارسال پیام همگانی (برودکست)
- مدیریت و تعریف کانال‌های اسپانسر از داخل ربات
- امکان تعیین محدودیت دانلود روزانه

## پیش‌نیازها و راه‌اندازی

1. نصب وابستگی‌ها:
```bash
npm install
```

2. تنظیم متغیرهای محیطی:
فایل `.env.example` را به `.env` تغییر نام داده یا کپی کنید و مقادیر مورد نیاز را وارد کنید:
```bash
cp .env.example .env
```

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_ID` | شناسه عددی ادمین |
| `MAIN_CHANNEL_ID` | شناسه عددی کانال اصلی |
| `VIDEO_DELETE_DELAY` | مدت زمان نمایش ویدیو به ثانیه (پیش‌فرض: 30) |
| `DAILY_LIMIT` | سقف دانلود روزانه برای هر کاربر (0 = نامحدود) |

3. اجرای ربات:
```bash
npm run dev   # حالت توسعه
npm start     # حالت پروداکشن
```

## راهنمای استفاده

### دستورات ادمین
- `/panel`: ورود به پنل مدیریت، آمار، مدیریت اسپانسرها و برودکست
- `/add`: آپلود و ثبت ویدیوی جدید و دریافت لینک اختصاصی

### افزودن کانال اسپانسر
از پنل مدیریت بخش «مدیریت اسپانسرها» فرمت زیر را ارسال کنید:
```text
شناسه_عددی_کانال | نام کانال | لینک کانال
```
مثال:
```text
-1001234567890 | کانال اول | https://t.me/channel_username
```

> توجه: ربات باید در کانال‌های اسپانسر دسترسی ادمین داشته باشد تا بتواند عضویت کاربران را بررسی کند.

## نکات امنیتی

- فایل `.env` را هرگز در مخزن عمومی قرار ندهید.
- دسترسی به بخش‌های مدیریتی تنها برای شناسه تعریف‌شده در `ADMIN_ID` امکان‌پذیر است.
